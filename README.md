## 📌 About The Project

**C Language Mastery** ek **complete C programming repository** hai jisme aapko milega:

- 🔹 **Basic se Advanced** concepts tak ka code
- 🔹 **Well-commented** aur **easy to understand** examples
- 🔹 **Interview & Exam** ke liye ready-made programs
- 🔹 **Topic-wise** folders with clear naming
- 🔹 **Regularly updated** with new content

> 💡 *"C is the language of the system – learn it, and you will understand how computers really work."*

---

## ✨ Features

- ✅ **100+ C Programs** – har topic ke liye multiple examples
- ✅ **Beginner Friendly** – zero coding experience se start kar sakte ho
- ✅ **Clean & Readable Code** – indentation aur comments ke saath
- ✅ **Algorithms & Data Structures** – linked list, stack, queue, sorting, searching
- ✅ **File Handling & Dynamic Memory** – real-world programming concepts
- ✅ **Free & Open Source** – koi bhi contribute kar sakta hai

## 📚 Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | **Hello World & Basic Syntax** | Program structure, comments, escape sequences |
| 2 | **Variables & Data Types** | int, float, char, double, type casting |
| 3 | **Operators** | Arithmetic, relational, logical, bitwise, assignment |
| 4 | **Conditional Statements** | if, if-else, nested if, switch-case |
| 5 | **Loops** | for, while, do-while, nested loops, patterns |
| 6 | **Arrays** | 1D, 2D, multi-dimensional, matrix operations |
| 7 | **Strings** | String functions, manipulation, arrays of strings |
| 8 | **Functions** | User-defined functions, recursion, call by value/reference |
| 9 | **Pointers** | Pointer basics, arithmetic, pointers with arrays/functions |
| 10 | **Structures & Unions** | Struct definition, nested structures, typedef, union |
| 11 | **File Handling** | Read, write, append, binary files, file operations |
| 12 | **Dynamic Memory Allocation** | malloc, calloc, realloc, free |
| 13 | **Data Structures** | Linked list, stack, queue, trees, graphs |
| 14 | **Sorting & Searching** | Bubble, selection, insertion, merge, quick, binary search |
