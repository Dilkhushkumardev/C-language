## ⚡ How to Compile & Run

### 🛠️ Prerequisites
Ensure you have a C compiler installed on your system:
- **Windows**: MinGW-w64 / GCC or Clang
- **Linux (Ubuntu/Debian)**: `sudo apt install build-essential`
- **macOS**: `xcode-select --install`

---

### 💻 Command Line (Terminal / PowerShell / Bash)

#### 1. Clone the Repository
```bash
git clone https://github.com/Dilkhushkumardev/C-language.git
cd C-language
```

#### 2. Compile Any C Program
Using **GCC**:
```bash
# Basic compilation
gcc C_Programming/Question_1.c -o Question_1

# With all standard warnings enabled (Recommended)
gcc -Wall -Wextra -std=c11 C_Programming/Question_80.c -o Question_80
```

Using **Clang**:
```bash
clang -Wall -std=c11 C_Programming/Question_1.c -o Question_1
```

#### 3. Execute the Binary
- **Windows (CMD / PowerShell)**:
  ```powershell
  .\Question_1.exe
  ```
- **Linux / macOS**:
  ```bash
  ./Question_1
  ```

## 💡 Featured Coding Exercises

Here is a quick snapshot of common problems solved inside this repository:

<details>
<summary><b>🔍 1. Check Palindrome Sentence (Question_80.c)</b></summary>

```c
#include <ctype.h>
#include <stdio.h>
#include <string.h>

#define MAX 100

int main() {
    char str[MAX];
    int i, len, flag = 1;

    printf("Enter a sentence: ");
    fgets(str, sizeof(str), stdin);
    str[strcspn(str, "\n")] = 0; // Strip trailing newline

    len = strlen(str);
    for (i = 0; i < len / 2; i++) {
        if (tolower(str[i]) != tolower(str[len - i - 1])) {
            flag = 0;
            break;
        }
    }

    if (flag)
        printf("The sentence is a palindrome.\n");
    else
        printf("The sentence is not a palindrome.\n");

    return 0;
}
```
</details>

<details>
<summary><b>🔍 2. Book Information Record using Structures (Question_150.c)</b></summary>

```c
#include <stdio.h>
#include <string.h>

struct Book {
    char title[100];
    char author[100];
    float price;
};

int main() {
    struct Book book1;

    printf("Enter book title: ");
    fgets(book1.title, sizeof(book1.title), stdin);
    book1.title[strcspn(book1.title, "\n")] = '\0';

    printf("Enter author: ");
    fgets(book1.author, sizeof(book1.author), stdin);
    book1.author[strcspn(book1.author, "\n")] = '\0';

    printf("Enter price: ");
    scanf("%f", &book1.price);

    printf("\n--- Book Details ---\n");
    printf("Title  : %s\n", book1.title);
    printf("Author : %s\n", book1.author);
    printf("Price  : $%.2f\n", book1.price);

    return 0;
}
```
</details>
